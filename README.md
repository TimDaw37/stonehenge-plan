# A georeferenced plan of Stonehenge

Live: https://timdaw37.github.io/stonehenge-plan/

Scroll to zoom, drag to pan, click for an OSGB coordinate. **numbers off** / **numbers on** toggles the Atkinson/Cleal stone numbers.

The drawing is the 1990 measured survey (M. J. Reek / Rees for English Heritage), georeferenced from that sheet’s own OSGB ticks. It is not a GNSS ground survey. Other published OSGB plans (for example Cleal 1995) sit about two to five metres away on the same stones. Use it as a click-plan, not as proof of a fraction of a degree.
